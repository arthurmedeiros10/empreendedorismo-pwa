# Empreendedorismo PWA

Um Progress Web App focado em empreendedorismo.

## Sobre

Este projeto é um PWA (Progressive Web App) destinado a empreendedores, com foco em acessibilidade offline, instalação em dispositivos móveis e experiência de usuário otimizada.

## Funcionalidades

- Interface responsiva
- Funcionamento offline
- Instalável em dispositivos móveis
- Leve e rápido

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Service Workers
- Web App Manifest

## Como executar

Clone o repositório e abra o arquivo `index.html` em seu navegador:

```bash
git clone https://github.com/arthurmedeiros10/empreendedorismo-pwa.git
cd empreendedorismo-pwa
```

Em seguida, sirva os arquivos com um servidor local (ex: Live Server do VS Code).
